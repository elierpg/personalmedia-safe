# Mi Media Server Personal (personal)

Este Space es una instancia **personal y autoalojada** para organizar y reproducir **mi propio contenido** almacenado en mis canales/cuentas de Telegram de forma privada.

## Uso previsto
- Uso **personal/privado**.
- Solo contenido del que soy propietario o para el que tengo los derechos/permisos necesarios.
- No se ofrece como servicio público de distribución de contenido de terceros.

## Configuración
La aplicación se configura mediante **Variables y Secrets** del Space (no incluyas credenciales en el repositorio):
- Credenciales de Telegram (API ID/Hash, bot, etc.)
- Base de datos (MongoDB)
- URL base y claves opcionales (p. ej. TMDB)

Consulta el archivo `sample_config.env` incluido en este repositorio para ver las variables disponibles.

## Aviso
Este proyecto se proporciona tal cual para fines personales. El administrador del Space es responsable del contenido que indexa y de cumplir las políticas de la plataforma y la legislación aplicable.
